How it works
Settings and defaults
Left as they come, none of these settings can remove a file — from your phone or from OneDrive. Removing always follows something you chose.
Back up automatically
On
Backups run on their own, but only for albums you have given a mode.
Use mobile data
Off
Uploads wait for Wi-Fi, so a large backup never arrives on your bill.
New albums start as
Off
An album found later is not backed up until you choose a mode for it. Archive can never be this setting.
Optimise photos automatically
Off
Photos are only made smaller when you tap Optimise.
Backs up into
Changed by you

First backup runs
1 am, on charge
Only the first run waits — it is the big one. Sync now is never held, and the wait lifts for good once it finishes.
